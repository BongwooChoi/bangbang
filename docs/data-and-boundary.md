## 잇플 연동

공모전에서 안내한 [bccard-eatpl-search](https://github.com/NomaDamas/k-skill/tree/main/bccard-eatpl-search)의 공개 프록시를 서버에서 호출한다. `GET /api/restaurants`는 강남대로, 효령로, 도곡로, 역삼로, 서운로의 고정된 5개 검색만 수행한다. 임의 주소를 전달하는 범용 프록시나 전체 가맹점 수집 기능은 제공하지 않는다.

검색당 최대 100개 결과를 받은 뒤 좌표 변환, 지역 범위 검사, 상세 URL 검사, 중복 제거를 거쳐 화면에 표시한다. 모든 매장의 전체 목록이 아니며 원본 API의 순위·상한으로 일부 매장이 빠질 수 있다. 데이터는 파일·DB·공유 URL에 축적하지 않고 요청 처리와 현재 화면의 메모리에만 둔다. 앱 API 응답과 서버의 upstream fetch는 `no-store`다. 프록시 제공자가 운영하는 캐시는 별도다.

TM128 좌표는 Proj4로 WGS84로 변환한다. 선택한 변환식은 Kakao의 동일 매장 주소와 약 20m 이내로 맞는지 교차 확인했다. 측량·정확한 출입구 좌표를 보장하지 않는다. 거리 표시는 뱅뱅사거리 기준 직선거리이며 도보 시간이나 경로가 아니다.

전국·지역 백분위는 숫자가 작을수록 동일 업종 내 매출 상위다. 값이 없으면 미확인으로 남긴다. 예상 영업시간은 결제 이력에서 추정한 것이므로 공식 영업시간이나 실시간 영업 상태로 표시하지 않는다. 출처는 `eat.pl 잇플 · BC카드 결제 데이터 기반`으로 노출한다.

## 지도

Leaflet과 OpenStreetMap 표준 타일을 사용한다. [타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 현재 화면의 일반적인 지도 표시만 수행하며 출처를 항상 표시한다. 브라우저의 기본 HTTP 캐싱은 유지하고 지도 타일을 서비스 워커에 저장하거나 오프라인 지도를 내려받지 않는다. 유입 증가 시 별도 타일 제공자로 전환할 수 있도록 URL과 출처 환경 변수를 지원한다.

## 공유와 저장

브라우저에 담아두는 값과 공유 링크에는 검증된 가맹점 식별자만 사용한다. 공유 페이지는 최대 5곳을 현재 조회 결과에서 다시 찾는다. 목록에서 빠진 매장은 미확인 안내를 제공한다. API 응답의 `merUrl`은 바꾸지 않고 사용자가 클릭했을 때만 새 창으로 연다.

카카오 개발자 키가 있으면 공식 SDK를 사용하고, 없는 환경에서는 기기의 공유 창에서 카카오톡을 선택하는 방식으로 작동한다. 기기 공유를 지원하지 않으면 링크 복사를 제공한다. 카카오 전용 템플릿 연동에는 별도의 개발자 앱·도메인 등록이 필요하다.
