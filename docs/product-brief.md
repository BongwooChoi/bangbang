# 뱅뱅사거리 직장인 맛집 지도 기획

최종 업데이트: 2026년 11월 8일

## 서비스 방향

뱅뱅사거리에 있는 회사의 동료들을 첫 사용자로 삼아, 주변 직장인이 식사할 음식점을 찾고 선택할 수 있는 지도를 만든다. 뱅뱅사거리를 중심으로 강남역과 양재역 부근까지 다룬다. 공모전 배경과 연동 조건은 [공모전 조사 문서](contest-background.md)를 참고한다.

## 사용자 지정 지역 범위

| 구분 | 기준 |
| --- | --- |
| 중심 | 뱅뱅사거리 |
| 북쪽 한계 | 강남역 1번·8번 출구를 기준으로 그보다 북쪽으로 확장하지 않음 |
| 남쪽 한계 | 양재역 1번·4번 출구를 기준으로 그보다 남쪽으로 확장하지 않음 |

사용자 원문: “강남역 방향은 1번 8번 출구를 이상 위로 넘지 않게. 양재역 방향은 1번 4번 출구 이하 아래로 내려가지 않게.”

출구 기준은 후보 음식점의 포함 범위에 적용한다. 지도 구현 시 출구의 실제 위치를 확인하여 경계로 변환한다. 아직 좌표나 경계 폴리곤을 확정하지 않았다.

앞선 “반대편 대로까지 넘어가지 않는 선”이라는 조건을 강남대로 한쪽만 포함하라는 뜻으로 확정하지 않는다. 위 발언으로 남북 한계는 정해졌으며, 동서 폭과 세부 도로 경계는 지도 설계 때 구체화한다.

## 초기 기능 제안

아래는 대화에서 제안한 초안이며 개별 기능의 구현 범위는 후속 기획에서 정한다.

- 뱅뱅사거리 중심 지도와 음식 종류 필터
- 잇플의 동네 고객 비율·매출 순위 정보를 활용한 후보 비교
- 오늘의 후보 추천과 동료에게 후보 공유
- 반환된 주소를 그대로 사용하는 잇플 상세 페이지 연결

‘뱅뱅밥’은 제안된 이름이며 최종 서비스명은 미확정이다. 도보 시간·가격·웨이팅 정보는 별도 근거가 확보된 경우에만 제공한다.

## 공개 개발과 운영 방향

- GitHub의 공개 저장소 `BongwooChoi/bangbang`에서 개발하고, 다른 사람이 Issue와 Pull Request로 개선에 참여할 수 있게 한다.
- 프로젝트가 작성한 코드와 문서는 MIT 라이선스로 공개한다. 잇플 데이터, 지도, 사진 및 제3자 상표에는 각 제공자의 이용 조건을 적용한다.
- 호스팅은 Vercel을 우선 검토하며 무료 운영을 목표로 한다. 단, Hobby는 개인·비상업 용도만 허용하므로 유입 리워드를 받는 공모전 서비스의 사용 가능 여부를 확인해야 한다. 유료 플랜 전환은 별도 결정한다.
- 모바일 사용 경험을 우선하고, 홈 화면에 추가할 수 있는 PWA로 구현한다. 설치하지 않은 방문자도 같은 핵심 기능을 사용할 수 있어야 한다.
- 추천 음식점과 후보 목록을 카카오톡 및 다른 SNS로 쉽게 공유할 수 있게 한다. 카카오톡 전용 공유, 기기 기본 공유, 링크 복사를 제공한다.

구체적인 요구사항과 검증 항목은 [모바일 및 공유 설계](mobile-and-sharing.md)를 참고한다.
