# 첫 버전 검증 기록

## 추천·고객층 필터 확장 검증 (2026년 11월 8일)

- 기존 테스트 10개 통과를 기준으로 구현을 시작했다. 고객층 정규화, 성별·연령대의 동일 항목 매칭, 회식과 다른 필터의 교집합, 추천 점수와 결측값, 시간 구간 검증을 추가해 총 18개 테스트 통과. 타입 검사와 프로덕션 빌드 통과.
- Chromium 360px에서 ‘30대 여성 + 회식 후보’ 결과가 실제 API의 동일 조건과 일치하는지 확인. 카드의 일치 이유와 회식 배지, 상세의 고객층 순위·요일·시간 구간을 확인했다.
- 추천순·거리순 전환, 검색 결과 없음과 전체 조건 복원, 목록에서 지역 전환과 상세 열기, 지도 추천 후보 열기, 공유 링크 직접 접근을 확인했다.
- 목록 모드의 숨겨진 지도에서 Leaflet 이동 애니메이션이 0 크기를 계산해 발생하던 `Invalid LatLng object: (NaN, NaN)` 오류를 재현하고 수정했다. 수정 후 같은 모바일 동선에서 상세 표시와 오류 없는 실행을 확인했다.
- 360px·1440px 화면에서 가로 넘침 없음. 서비스 워커 업데이트 버튼으로 `bangbang-shell-v1`에서 `v2`로 전환하고 구 캐시 정리를 확인했다.
- 위 검증은 화면 크기 에뮬레이션이며 실제 휴대폰·카카오톡 전송 검증은 아니다.

검증일: 2026년 11월 8일. Windows의 Chromium 브라우저와 로컬 프로덕션 빌드를 사용했다. 모바일 검증은 화면 크기 에뮬레이션이며 실제 휴대폰 검증과 구분한다.

## 확인한 항목

- `npm run typecheck`, `npm test` 10개, `npm run build` 통과.
- 공개 저장소의 [GitHub Actions 실행](https://github.com/BongwooChoi/bangbang/actions/runs/42433521214)에서도 Ubuntu·Node.js 24 환경의 설치, 타입 검사, 테스트, 빌드 통과.
- `npm audit --omit=dev`: 알려진 취약점 0개.
- 실제 API에서 지정 범위 안 음식점 146개 조회. 수량은 제공 데이터에 따라 달라진다.
- 데스크톱 및 390px·360px 모바일 화면을 확인했고 가로 넘침이 없었다.
- 모바일 지도 기본 표시, 목록 전환, 검색, 음식 종류 필터, 상세 정보, 즐겨찾기와 복원, 20개 단위 더 보기 확인.
- 음식점 공유 URL 직접 접근 시 후보와 해당 음식점 이름의 Open Graph 제목 복원 확인. 링크 복사 성공 확인.
- 서비스 워커 등록과 캐시 내용 확인. API 응답, 음식점 HTML, 지도 타일을 서비스 워커에 저장하지 않는다.
- 로컬 원본 서버를 중지한 뒤 새 URL 탐색에서 오프라인 안내 표시 확인. 서버 재시작 후 음식점 목록 복구 확인.
- 모바일 주요 버튼과 지도 마커에 접근 가능한 이름이 있는지 확인.

## 공개 배포 확인

- 운영 주소: https://bangbang-five.vercel.app — 기존 Vercel Hobby 계정에 배포.
- 인증 없는 HTTP 요청에서 음식점 API 200 응답, 후보 146곳, `partial: false`, `Cache-Control: no-store` 확인.
- 운영 주소의 390px 화면에서 가로 넘침 없이 지도 타일과 음식점 표시 확인.
- 공유 페이지 직접 접근 시 후보 1곳 복원, 음식점 이름을 포함한 제목, 운영 도메인의 Open Graph 이미지·URL 확인.
- Manifest 200 응답 및 standalone 설정, 서비스 워커 200 응답 및 갱신용 캐시 헤더 확인.

## 아직 실제 기기에서 확인하지 않은 항목

- Android Chrome·Samsung Internet 및 iPhone Safari의 설치와 standalone 실행.
- 실제 카카오톡 메시지 전달과 인앱 브라우저, SNS 미리보기 서버의 캐시 갱신.
- Kakao 전용 SDK: JavaScript 키와 도메인 등록 후 검증 필요. 현재는 기기 기본 공유 또는 링크 복사를 사용한다.
- 스크린리더, 가상 키보드, 기기 안전 영역, 실제 위치 권한 흐름.
- 새 버전 서비스 워커 업데이트 및 외부 제공자 장애가 실제 운영 중 발생하는 상황.
- 공모전 참가 등록과 유입 집계 대시보드 반영.

위 항목을 통과했다고 간주하지 않는다. 실제 메시지 전송은 브라우저 검증 과정에서 수행하지 않았다.
